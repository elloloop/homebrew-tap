# elloloop/homebrew-tap

Homebrew formulas for elloloop tools.

## Usage

```sh
brew tap elloloop/tap
brew install devpod
```

## Available formulas

| Formula | Description |
| --- | --- |
| `devpod` | Local-first GitHub Actions runner and stacked-diff CLI — see [elloloop/devpod](https://github.com/elloloop/devpod) |
